# FIFA World Cup Data Analysis | Power BI

## Project Overview
This project is a FIFA World Cup Data Analysis Dashboard developed using Microsoft Power BI. It is designed to explore World Cup-related data and present analytical information through data visualization.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Objectives
- Explore FIFA World Cup data.
- Analyze football-related data and trends.
- Present meaningful information through visualizations.
- Develop an interactive Power BI report.

## Project File
- `Fifa_World_Cup_Pro.pbit` – Power BI report template.

## How to View the Project
1. Download the `.pbit` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Connect to the required data source if prompted.
4. Explore the report.
